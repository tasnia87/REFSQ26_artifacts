# REFSQ 2026 — Research Artifacts

This repository contains research artifacts associated with a study of **creativity in software requirements engineering**, including requirements datasets, evaluation materials, experimental results, and code-related resources.

The artifacts are shared to support transparency, inspection, and further research into the generation and evaluation of creative software requirements.

## Research context

Creative requirements engineering investigates ways to identify and formulate software requirements that go beyond conventional feature descriptions while remaining understandable and useful. This repository brings together materials relevant to studying the generation and assessment of such requirements.

The study's broader research context includes automated requirement generation and human evaluation of requirement quality. Readers should consult the accompanying paper for the precise research questions, experimental protocol, participant information, and interpretation of results.

## Accessing the artifacts

Clone the repository:

```bash
git clone https://github.com/tasnia87/REFSQ26_artifacts.git
cd REFSQ26_artifacts
```

The `.xlsx` datasets can be opened in Microsoft Excel or read using spreadsheet-compatible analysis software. The survey-related PDF can be opened in a PDF reader.

### Code and reproducibility

The repository includes a `code/` directory. Before executing any scripts, review the instructions, dependency files, configuration, and data paths provided within the relevant subdirectory.

**Reproducibility note:** A complete, verified command sequence for regenerating the results has not yet been documented in this README. The exact correspondence between individual scripts, datasets, and result files should be confirmed from the repository contents and the accompanying paper.

## Suggested workflow for readers

1. Read the accompanying research paper to understand the study design and evaluation criteria.
2. Inspect the requirements-related spreadsheets and the second-study evaluation dataset.
3. Review the survey material to understand the data-collection instrument.
4. Examine `results/` for reported experimental outputs.
5. Inspect `code/` for implementation resources and any available reproduction instructions.
